# To-Do App ✅

## About

This is a simple To-Do App created using HTML and CSS. It provides a clean and simple interface for managing daily tasks.

## Technologies Used

- HTML
- CSS

## Files

- `to-do app.html` – Main HTML file for the To-Do App
- `style.css` – Styles and layout of the application
- `delete.png` – Delete icon used in the application

## Features

- Add and manage tasks
- Simple and clean user interface
- Delete icon for removing tasks
- Easy-to-use design

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `to-do app.html` in a web browser.

## Purpose

This project was created to practice HTML and CSS by building a simple To-Do application.
